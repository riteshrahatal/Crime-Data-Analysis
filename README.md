# Crime Data Analysis – India (2020–2024)

## 📌 Project Overview

This project analyzes crime data collected from multiple cities across India between **2020 and 2024**. The dataset provides information about different types of crimes, locations, victims, weapons used, police deployment, and case closure status.

The analysis aims to identify crime patterns, trends, and insights that can help understand crime risk across different cities and demographics.

---

## 📊 Dataset Information

| Feature | Details |
|---|---|
| Dataset | `crime_dataset_india.csv` |
| Rows | 40,160 |
| Columns | 14 |
| Cities | 29 |
| Crime Types | 21 |
| Time Period | 2020–2024 |

### Dataset Features

The dataset contains information related to:

- **Crime Type and Domain** – Different categories and domains of criminal activities
- **Date and Time** – Date and time when the crime occurred
- **Location** – City and geographical information
- **Weapon Used** – Type of weapon involved in the crime
- **Victim Demographics** – Victim age and gender
- **Police Deployment** – Information related to police presence/deployment
- **Case Status** – Case closure and investigation status

---

## 🎯 Objectives

The main objectives of this project are:

- Explore crime trends across different years and time periods
- Analyze different crime types and identify common categories
- Compare crime patterns across Indian cities
- Analyze victim demographics such as age and gender
- Study the relationship between crimes and weapons used
- Evaluate case closure rates
- Compare case closure performance across cities
- Identify potential high-risk cities and crime categories
- Generate actionable insights for policymakers and law enforcement agencies
